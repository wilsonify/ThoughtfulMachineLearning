# Firefox Browser Plugin

This Firefox browser plugin allows you to view the output of your REST API on a web page that contains the input data.

## Installation

1. Clone or download this repository.

2. Open Firefox and enter `about:debugging` in the address bar.

3. Click on the "This Firefox" menu and select "Load Temporary Add-on".

4. In the file dialog, navigate to the directory where you cloned/downloaded this repository and select
   the `manifest.json` file.

5. The plugin should now be loaded and you should see its icon in the Firefox toolbar.

## Usage

1. Make sure your REST API is running and accessible.

2. Visit a web page that contains the input data you want to send to the API.

3. Click on the plugin icon in the Firefox toolbar to open the popup.

4. The popup will display the input data and the prediction output returned by your REST API.
